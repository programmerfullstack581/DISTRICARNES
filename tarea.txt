# TAREA: REDISEÑO COMPLETO DEL MODO CLARO Y MODO OSCURO — DISTRICARNES

## CONTEXTO DEL PROYECTO

Estoy trabajando en el proyecto web de **DISTRICARNES HERMANOS NAVARRO**.

URL de producción:

https://districarnes-83qm.onrender.com/

El proyecto ya tiene **modo claro y modo oscuro**, pero actualmente considero que el modo oscuro tiene una apariencia visual mucho mejor que el modo claro.

Quiero mejorar completamente el sistema de temas.

### OBJETIVO PRINCIPAL

El **modo oscuro actual debe utilizarse como referencia visual principal**.

El objetivo NO es simplemente invertir colores ni poner fondos blancos.

Quiero que:

* El modo oscuro conserve su identidad visual actual.
* El modo claro tenga una apariencia profesional, limpia y moderna.
* Ambos modos tengan exactamente la misma estructura, componentes y funcionalidades.
* Todos los elementos de la interfaz se adapten correctamente al tema seleccionado.
* No existan textos blancos sobre fondos claros ni textos oscuros sobre fondos oscuros.
* No existan componentes que permanezcan con colores incorrectos después de cambiar de tema.
* El cambio entre temas sea completo y consistente en toda la aplicación.

# 2. REGLA PRINCIPAL DEL REDISEÑO

El modo oscuro actual debe ser tratado como la referencia visual.

NO quiero destruir el diseño oscuro para crear el claro.

La relación debe ser:

```text
MODO OSCURO
        ↓
REFERENCIA VISUAL
        ↓
MODO CLARO EQUIVALENTE
```

No:

```text
MODO OSCURO
        ↓
invertir colores
        ↓
MODO CLARO
```

---

# 3. CREAR UN SISTEMA DE VARIABLES DE TEMA

Si el proyecto lo permite, centraliza los colores mediante variables CSS.

Por ejemplo:

```css
:root {
    /* Tema claro */
}

[data-theme="dark"] {
    /* Tema oscuro */
}
```

O utiliza el sistema de theming que ya tenga el proyecto si es más apropiado.

No quiero tener cientos de colores independientes repartidos por todo el código.

Centraliza:

* fondo principal
* fondo secundario
* tarjetas
* superficies
* texto principal
* texto secundario
* texto deshabilitado
* bordes
* sombras
* inputs
* botones
* enlaces
* estados
* alertas
* navbar
* footer
* modales
* dropdowns
* tablas

# 4. MODO CLARO

El modo claro debe ser elegante y profesional.

NO utilices blanco puro en absolutamente toda la interfaz.

Recomendación conceptual:

### Fondo principal

Utilizar un gris muy claro/neutro.

Ejemplo conceptual:

```text
#F5F6F8
```

### Tarjetas

Blanco o un tono muy cercano:

```text
#FFFFFF
```

### Texto principal

Gris muy oscuro:

```text
#1F2937
```

### Texto secundario

Gris medio:

```text
#6B7280
```

### Bordes

Gris suave:

```text
#E5E7EB
```

### Sombras

Muy suaves.

NO utilizar sombras negras fuertes.

# 8. BOTÓN DE CAMBIO DE TEMA

# 9. TRANSICIÓN ENTRE TEMAS

Implementar una transición visual sutil.

Por ejemplo:

```css

    background-color 0.2s ease,
    color 0.2s ease,
    border-color 0.2s ease,
    box-shadow 0.2s ease;
```

No utilizar animaciones exageradas.

El cambio debe sentirse profesional.
